# Task Graph：长程任务看板设计

日期：2026-09-30

## 目标

为用户和 AI 代理提供同一个可持久化的项目工作台。以有向图展示阶段任务及依赖，明确任务状态、验收标准、验收证据；保留计划、Roadmap 和执行记录，帮助长程任务在中断后恢复。

用户明确要求：有向图、阶段任务、任务状态、验收标准与情况、炫酷简约风、供用户直观查看和代理使用、保存计划与 Roadmap 文档。

本草案的默认假设：第一版服务本机单用户，可含多个项目；不包含登录、多人实时协同和云端部署。

## 方案比较

1. 推荐：本地网页 + Node.js 服务 + 文件存储。用户通过网页编辑，代理通过 HTTP API 读写同一份数据；计划和 Roadmap 以 Markdown 文件保存。可备份、可搬迁，不依赖外部服务。
2. 纯 HTML + 浏览器存储：打开方便，但代理无法直接读取浏览器数据，难以可靠共享任务状态。
3. 云端应用 + 数据库：适合多人协作，但增加账号、部署和运维成本，不作为首版范围。

## 页面与视觉

使用低饱和深色底、细线网格、青绿色当前任务强调色、少量光晕和克制的交互动画；状态同时以文字、图标和颜色表示。

桌面布局：左侧项目与文档导航；中央可缩放、平移的任务图；右侧选中任务的详情和验收区域。顶部展示项目名称、完成进度、阻塞数、可推进阶段数和保存状态。

任务节点显示阶段编号、名称、状态、负责人、验收完成比例。箭头明确“前置任务 → 后续任务”。选中节点突出其上游与下游，其他节点降低视觉权重。提供搜索、状态筛选、自动布局和适应画布。

窄屏将详情改为抽屉，保留横向可移动画布。图操作有按钮与键盘入口，不能只依赖鼠标手势。

## 任务与依赖规则

任务字段：稳定 ID、标题、描述、负责人、状态、验收项、证据、关联文档、画布位置、更新时间。

状态：待开始、进行中、待验收、已完成、阻塞。任务状态与验收情况分别记录，不能用“已完成”替代验收证据。

每条验收项包含标准文本、结果（未验收／通过／未通过）、证据或备注、更新时间。

依赖采用有向无环图（DAG）：禁止自依赖、重复边、指向不存在任务的边以及形成环的连接；新增和导入时均校验。一个节点允许多个前置与多个后续。

“可推进”指任务尚未完成且所有前置任务已完成。前置未完成的任务可查看和编辑，但不能开始或标记完成。明确展示阻塞来源，不自动修改用户记录的状态。

任务完成条件：所有验收项通过且前置任务完成。没有验收项的任务不能完成。拒绝不符合条件的状态更新，并说明原因。

删除任务需要确认，连带移除其依赖边；删除被后续任务依赖的节点时明确提示影响。

## 文档

支持创建、编辑、查看和删除 Markdown 文档，类型包括 Plan、Roadmap、Notes。可将文档关联到任务。

内置轻量、安全的 Markdown 预览；禁止执行文档中的 HTML 或脚本。长内容可滚动；编辑后明确显示保存中、已保存、保存失败。

项目导出 JSON 包含完整任务、依赖、验收项和文档内容，可导入恢复。导入先完整校验，失败不能覆盖原项目。

## 代理工作流

提供本地 HTTP API 读取项目快照、新增或更新任务、修改验收项、管理依赖和文档。UI 与 API 共用服务端校验。

以稳定 ID 引用任务。每次写入携带项目 revision；版本冲突返回 409，代理或网页重新读取后再提交，防止互相覆盖。

执行时可记录：当前阶段、已完成工作、验证结果、阻塞原因和下一步。提供 AGENT_GUIDE.md，说明从读取项目到推进阶段、提交证据与保存恢复记录的实际调用示例。

默认绑定 127.0.0.1，不直接暴露公网。不会自动执行任务节点里的文字或文档命令。

## 存储与实现边界

新建独立目录 /home/projects/task-graph，避免改动已有项目。

Node.js 服务提供静态页面和 JSON API；原生 HTML/CSS/JavaScript + SVG 绘图，首版无外部运行时依赖。项目元数据与任务存 JSON，文档使用内部生成的安全文件 ID 保存为 Markdown，用户标题不作为路径。

服务端串行化写入并使用临时文件加原子替换；更新先验证再提交。文档与项目引用的提交必须可恢复，不能出现任务已关联但文档写入失败的半完成状态。

首个示例项目明确标注“示例”，演示规划、并行实现、集成、验收和交付，不冒充实际完成记录。

## 验证与交付标准

- 图校验覆盖环、自依赖、无效 ID、重复边、多前置与多后续。
- 状态变更覆盖前置未完成、验收未通过、无验收项和符合完成条件。
- 持久化覆盖重启恢复、版本冲突、错误输入不覆盖原数据。
- 文档覆盖中文、Markdown、脚本注入文本和异常路径输入。
- 浏览器验证创建阶段、连接依赖、编辑验收、保存文档、图布局、缩放、筛选和导入导出。
- 交付启动命令、访问地址、数据位置、代理调用说明和实际测试结果。
