# Task Graph

一个给用户与 AI 代理共同使用的长程任务工作台。任务以有向无环图展示：阶段、前置依赖、状态、验收标准和证据放在同一个位置。计划、Roadmap 和交接记录支持 Markdown 编辑与预览。

## 启动

需要 Node.js 22 或更新版本。运行应用无需安装依赖：

```bash
cd /home/projects/task-graph
npm start
```

浏览器打开 http://127.0.0.1:4310 。首次启动会创建明确标注的示例项目。

可设置 `PORT` 和 `TASK_GRAPH_DATA`，例如：

```bash
PORT=4320 TASK_GRAPH_DATA=/home/projects/task-graph/my-data npm start
```

服务只绑定本机地址，适合本地个人工作台；当前不包含账号、云同步或多人实时协作。

## 日常使用

左侧“我的项目”可展开或收起项目列表，点击具体项目进入任务图；切换项目会清空上一个项目的搜索与状态筛选。地址中的 `?project=项目ID` 可以直接打开指定项目。

右上角配色下拉框可选择“经典深色”“经典浅色”“薄荷浅色”“深海青绿”，选择会在当前浏览器中保留，刷新后在样式加载前应用。新增配色分别采用白底薄荷面板＋深紫按钮、深蓝底＋青绿按钮＋红色警示；任务状态保持独立的高对比语义色。切换只改外观，不清空未保存的任务或文档。顶部统计以紧凑信息条展示，项目文档统一从左侧“项目文档”进入。

“新建阶段”位于任务图工具栏，与“连接”“整理”并列；项目标题旁保留导入、导出。手机端三个操作保持同组显示为图标按钮，可通过可访问名称和提示区分。

主题、任务状态、文档范围/用途、验收项及弹窗内的下拉选择统一使用圆角浮层：跟随四种配色，支持长列表滚动、触摸、方向键/Home/End、Enter 确认、Escape 取消和 Tab 离开。点击外部、页面滚动或控件被移除/禁用/隐藏时自动关闭；原有表单值与保存逻辑保留。浏览器自身的文件选择器和安全确认窗口仍由系统提供。

左上角导航按钮可隐藏或恢复桌面侧栏，收起后任务区铺满页面，刷新仍记住选择。手机端仍用同一按钮展开导航；手机操作不会改变桌面的收起偏好。开关不会丢弃未保存的文档编辑。

1. 新建项目，写下目标与范围。
2. 新建阶段，填写负责人、说明和验收标准。
3. 点击“连接”，选择前置阶段 → 后续阶段；禁止依赖成环。
4. 点击节点，在右侧编辑状态、验收结果和证据，再点击“保存阶段”。
5. 在“项目文档”按需创建项目大纲、方案或其他文档，可关联到多个任务。
6. 结束工作前保存当前阶段与工作记录。下次打开继续。

节点可拖动调整布局。拖动空白区域平移，滚轮缩放，“整理”按依赖自动布局，“适应画布”显示全部。画布聚焦时支持方向键平移、加减键缩放、F 适应画布。Ctrl/⌘ + S 保存当前任务或文档。

### 如何选择文档位置

- **工作文档**：记录计划、方案和交接，可以放在项目或某个阶段下，并关联到多个阶段。
- **阶段验收**：记录某个阶段的验收过程，只能关联该阶段的验收标准。
- **已归档验收**：查看已删除阶段的验收记录，内容只读。

在文档页面先选择资料分类，再选择所属位置；“文档用途”用于描述内容，不改变文档归属。

### 节点专属文档

项目文档没有固定三件套，也不必创建任何文档。名称可自由填写，新建时默认“自由文档”，从空白开始；选择执行计划、工作路线等用途时，可勾选或取消内容模板。用途分类不会限制文档数量，也不会在修改分类时重写正文。已有文档保留，可自行重命名或删除。

节点详情的“关联文档”默认收起，点击“选择关联文档”展开可滚动的勾选列表。每个节点可关联零份、一份或多份文档，同一份项目大纲可被多个节点引用，内容只保存一份。勾选后点击“保存阶段”。列表中的箭头可打开文档。

每条验收标准可选择一份**本节点独立验收文档**，也可不关联。选择器旁的加号可新建并关联；已有未保存阶段修改时，会先询问是否保存。新建可选择模板或空白正文，箭头打开编辑页并可返回原节点。手动更换或解除关联后点击“保存阶段”。验收文档与普通文档分开存储，不能选择项目文档或其他节点验收资料；同一节点的多条标准可以共用一份。关联不会自动判定通过，也不能替代证据文字。

旧验收引用显示“旧普通文档关联 · 待转换”。点击“复制为验收文档”确认后，为当前节点建立独立副本并替换该项引用；原普通文档完整保留，之后两份正文各自维护。不自动批量转换。也可解除旧关联。

点击节点，在详情下方“节点文档”中选择“查看文件夹”或“新建文档”。可按需记录工作路线、技术实现、验证记录、决策与交接；不会自动创建空文档。进入文档页后可编辑、预览、保存，并通过“返回任务图”回到原节点。

文档页的“资料分类”切换工作文档、阶段验收和已归档验收；“所属位置”切换具体归属。左侧“项目文档”始终先进入普通全局目录；普通引用不会改变归属。侧栏数量仅计算普通文档，验收文档在节点独立区域计数。

“本地路径”显示并允许复制当前版本的真实目录。文件名和目录名使用稳定 ID，界面显示标题，因此重名或改名不会覆盖文件。每次保存生成新版本，路径随版本改变；旧版本仍保留。历史项目未生成的节点目录会在下一次保存节点或创建文档时生成，读取路径不修改项目。

本地文件用于查看和备份，编辑请在面板保存或通过代理 API 提交；直接修改历史 Markdown 文件**不会自动同步**。浏览器不直接启动系统文件管理器。

删除节点时，普通专属文档转为项目文档；验收文档独立归档，保留来源节点名和正文，不变成普通资料。“验收归档”中可阅读、复制正文或明确删除，不能编辑或被其他节点关联。删除验收文档仅解除其引用，保留验收标准、结果和证据。被远端删除的正文草稿恢复需确认并使用新 ID；原节点已删除时，只保留可复制草稿，不恢复成普通文档。

中文字体优先使用系统界面字体（Windows 微软雅黑、macOS 苹方），离线环境仍有随附字体后备；节点标题加深字重，状态图例放大并使用更高对比度的文字、圆点和紧凑色块。不同屏幕与非整数画布缩放仍可能有不同的抗锯齿观感。

已完成要求：至少一个验收项、每项通过并有非空证据、所有前置阶段已完成。进行中和待验收也要求前置阶段完成。上游状态变更若破坏已有下游状态，将被拒绝；需要先按从后向前的顺序调整下游阶段。

编辑不会自动保存文本：顶部会标记未保存修改，离开编辑、切换项目或刷新页面时会提醒。拖动节点会保存坐标。每 6 秒检查代理更新；有未保存编辑时保留草稿并提示新版本。遇到冲突，点击顶部同步按钮读取最新版本，核对保留的草稿后再保存。

## 数据与备份

默认目录：`data/projects/<项目ID>/`。

- `HEAD`：当前已提交版本目录的名称。
- `revisions/<版本目录>/snapshot.json`：完整项目快照。
- `revisions/<版本目录>/documents/<文档ID>.md`：该版本的 Markdown 文档。
- `revisions/<版本目录>/tasks/<节点ID>/documents/<文档ID>.md`：节点专属 Markdown 文档，每个节点有独立目录。
- `revisions/<版本目录>/tasks/<节点ID>/acceptance/<验收文档ID>.md`：当前节点独立验收文件。
- `revisions/<版本目录>/archived-tasks/<原节点ID>/acceptance/<验收文档ID>.md`：已删除节点的验收归档。

所有文件写入成功后才原子切换 `HEAD`，旧版本保留。备份整个 `data/` 目录即可。一个数据目录只能运行一个服务进程。

“导出”下载完整 JSON，包含任务、依赖、文档和活动记录。“导入”创建独立新项目，不覆盖原项目。可将旧版本的 `snapshot.json` 导入恢复。

完整项目 JSON 上限 7 MB，以保证导出的备份能够重新导入。历史版本目前不自动清理，频繁编辑和大型文档会增加磁盘占用；可定期备份，未来再增加保留策略。

单项目最多 250 个节点、2000 条依赖；普通、验收和归档文档合计最多 1000 份。单文档最多 500000 字符，单节点普通引用最多 100 份。新备份包含独立验收集合，旧版本应用不保证可读取；新版本可导入旧快照。

## 代理使用

见 [AGENT_GUIDE.md](AGENT_GUIDE.md)。代理通过本地 HTTP API 读取与更新同一份项目；无需操作浏览器，也不要直接编辑版本文件或 `HEAD`。

### Codex Skill

可复用技能源码位于 [skills/task-graph](skills/task-graph/SKILL.md)，包括使用流程、API 参考和无需第三方依赖的 Node.js 客户端。它用于讨论建计划、按授权推进阶段、维护普通/独立验收文档和恢复交接，不会自动运行看板或在会话结束后继续执行。

在能访问本地看板的 Codex 环境安装后，可以说：

```text
$task-graph 读取“视频 → 教程｜产品探索”，先和我讨论需求，把确认内容更新进看板，暂时不要开发。
$task-graph 继续这个项目，先读取文档和当前状态，告诉我下一步。
$task-graph 执行指定节点，记录真实验证证据，需要我确认的验收项保持待验收。
```

本机技能目录为 `/home/king/.codex/skills`；安装入口链接到上述源码，更新无需维护两份。其他使用 `.agents/skills` 的 Codex 环境，可以把该目录安装到用户级 `~/.agents/skills/task-graph` 或项目级 `.agents/skills/task-graph`；同一环境不要重复安装同名技能。未出现时新开会话或重启 Codex。

技能默认访问 `http://127.0.0.1:4310`，可通过 `TASK_GRAPH_URL` 指定另一个本机端口。远程/云端 Codex 的 localhost 不等于这台电脑，不能直接访问本地看板；需要另行设计连接与权限，不要直接公开当前无账号验证的服务。

只读检查：

```bash
node /home/projects/task-graph/skills/task-graph/scripts/task-graph.mjs list
```

客户端写入需要显式提供读取快照的 `revision`。冲突返回退出码 3，不自动重试或覆盖；连接丢失返回退出码 4，写入可能已经提交，需要先核对。删除/旧验收转换需用户明确意图及额外标志。安装和验证过程不创建或修改现有真实项目。
